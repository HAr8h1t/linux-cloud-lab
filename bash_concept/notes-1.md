What is Bash, and where is it used?
Bash = Bourne Again Shell
Bash is a command interpreter. You type commands, and Bash interprets them and runs programs or other operations.
It can also execute a saved sequence of commands from a file called a shell script, usually ending in .sh.


Think of the Linux system as a computer with many tools. Bash lets you operate those tools, combine them, and automate repetitive work.
For example, instead of manually creating five folders, checking files, and running commands every time, you can write one script to do it all
